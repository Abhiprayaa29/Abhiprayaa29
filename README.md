## Tentang Saya

Mahasiswa Teknik Informatika semester 5 di UPN "Veteran" Yogyakarta, dengan fokus pada pengembangan perangkat lunak dan perancangan UI/UX. Memiliki pengalaman sebagai asisten riset dosen dalam pembuatan wireframe dan prototype, serta minat pada AI agent orchestration dan keamanan siber.

Pengalaman lain mencakup pengelolaan AI coding agent untuk otomatisasi workflow, audit keamanan sistem, serta pengelolaan infrastruktur repositori GitHub. Kemampuan tambahan di bidang visual 3D (Blender, SketchUp) dan motion graphic (After Effects) turut mendukung proses perancangan produk digital.

Finalis dan peraih Best Video Award pada kompetisi UX Design nasional Find IT! UGM 2026.
